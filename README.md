# FPS Survival Game Inventory

![Unity](https://img.shields.io/badge/Unity-000000?logo=unity&logoColor=white)
![C#](https://img.shields.io/badge/C%23-512BD4?logo=csharp&logoColor=white)

An inventory system for a first-person survival game, built with Unity and ScriptableObjects.

## Features

- Item, food, tool and material ScriptableObjects
- Inventory data and UI slot controller
- First-person player movement and actions
- Uses the XEntity GameKit item system for the demo

## How to run

1. Clone the repository: `git clone https://github.com/Atthree/FPS-Survival-Game-Inventory.git`
2. Open the project folder with Unity Hub. Unity will import the project on first launch, which can take a few minutes.
3. Open the main scene in the `Assets/Scenes` folder and press **Play**.
